# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you find a security issue, please do not open a public issue. Instead, report it privately.

* **Email:** Send details to `shaunta.gates6911@gmail.com`.
* **Private Reporting:** Use [GitHub Private Vulnerability Reporting](https://github.com) if enabled on this repository.

### What to Include
Please provide as much detail as possible to help us fix the problem quickly:
* Type of issue (e.g., buffer overflow, SQL injection, cross-site scripting).
* Full paths of source file(s) related to the function.
* Step-by-step instructions to reproduce the issue.
* Impact of the issue and how an attacker could exploit it.

## Disclosure Policy

When you report a vulnerability, we follow these steps:
1. We will acknowledge your report within 48 hours.
2. We will work on a fix and keep you updated on our progress.
3. We ask that you keep the report confidential until we release a patch.
